# Local Sites showcase candidate

Buildless HTML/JavaScript in `dist/`. No backend, API calls, credentials, storage provisioning, or hosting registration. All agent and risk outputs are visibly simulated. The browser policy is illustrative, not an authorization service.

From this project folder, preview with `..\.venv\Scripts\python.exe -m http.server 8503 --directory dist --bind 127.0.0.1`.

Official Sites supports static assets and full-stack JavaScript/TypeScript on its supported runtime, with HTTP external connections and server-side secrets. It does not establish compatibility for the existing Python/Streamlit process. This static candidate has not been built or deployed by Sites, and account eligibility is unverified. A future live integration requires a server-side authenticated backend, gateway enforcement, bounded requests, and server-managed secrets; never add an API key to browser code.

Publishing, provisioning and pushing require user approval. No Site identity or deployment manifest has been created.

Reference: https://learn.chatgpt.com/docs/sites
